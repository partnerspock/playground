Developed a web-based Point of Sale (POS) and Warehouse Management System using PHP Laravel, designed to support payment processing, sales transactions, and inventory management within an integrated business application.

Implemented POS workflows for handling sales transactions and payment processing, alongside warehouse management functionality to support stock monitoring, inventory tracking, and stock movement operations.

Built the application using Laravel, PHP, HTML, and CSS, with Font Awesome integrated to enhance the user interface through consistent icons and visual elements.

Designed the system to streamline daily business operations by connecting point-of-sale activities with warehouse inventory workflows, improving transaction visibility and stock management.

Currently preparing the production deployment environment using a VPS, with domain configuration and final deployment planned as the next steps. Source code and version control are managed through GitHub.
